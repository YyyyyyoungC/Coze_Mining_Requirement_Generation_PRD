# PRD 文档输出格式模板

## 说明
- 公共模块（1-5、7-9）整合成一份基础文档
- 功能需求模块（第6部分）可以分批次输出多个功能文档
- 所有阶段完成后，将询问客户是否统一整合输出一份完整的 Markdown 文档
